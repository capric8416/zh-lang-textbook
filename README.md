# zh-textbook-parser

小学语文课本 PDF（人教版·二年级下册）排版块解析 → 语义单元 JSON。

## 用法

```bash
uv sync

uv run zh-textbook --printed 1-3                  # 按课本印刷页码，默认前 3 页
uv run zh-textbook --pages 6-8                    # 按 PDF 页序（1 基）
uv run zh-textbook --pages 1-130 -o out/all.json          # 全书：41 篇课文 + 8 个园地 + 3 张附录表
uv run zh-textbook --pages 1-130 --struct -o out/struct.json  # 简化结构，逐字注音
uv run zh-textbook --pages 1-130 --full -o out/pages.json     # 按页输出全部版面单元
uv run zh-polyphone out/struct.json -o out/polyphone.json     # 多音字、读音分组及组词
```

默认输出**课文**、**语文园地**、**附录**三部分，并且**一篇课文/一个园地是一个完整单元**：
跨页的会合并成一条。页眉、页脚、右边栏、课后仍然照常识别，但只用于把它们从
课文区里剔除，不写进结果。`--full` 改成按页输出，并带上这些版面单元。

### 多音字表

对任意 `--struct` 生成的 JSON，可重复生成多音字表：

```bash
uv run zh-polyphone out/zh-lang-grade2b-textbook-struct.json \
  -o out/zh-lang-grade2b-textbook-polyphone.json
```

每个多音字内部把全部读音分为 `本册出现`、`常用` 和 `不常用`：本册出现的
读音进入第一组；其余读音有组词的进入常用组，无组词的进入不常用组。每个字
的三个读音分组都按候选 `组词数量` 从多到少排列。每个读音都带组词，参数
`--words-per-reading` 默认为 `3`，可传其他正整数限制每个读音的组词数；传 `0`
表示组词数量不设上限。候选来自本册、pypinyin 短语表和 jieba 常用词表，统一
按照 jieba 的日常书面语词频从高到低选择，同频时优先短词。词典中的罕见读音
如果没有可用词条，`组词` 会保留为空数组。

## 输出结构

```jsonc
{
  "文件": "...", "总页数": 130,
  "课文": [{
    "课号": "1",              // 课文序号（页面上的橙色数字），栏目页为 null
    "栏目": null,             // 我爱阅读 / 口语交际 / 日积月累 …，正课为 null
    "课题": "古诗二首",        // 一课含多篇时的总标题，否则 null
    "标题": "咏柳",
    "标题注释号": "①",         // 标题上的 ①，对应「注释」里的条目
    "作者": "贺知章", "年代": "唐",
    "国别": null, "译者": null, "出处": null,
    "作者出处": "作者行",       // 作者是从「作者行」还是「注释①」里读出来的
    "页码": [1], "pdf页序": [6],
    "段落数": 1, "句数": 4,
    "全文": "碧玉妆成一树高，万条垂下绿丝绦。…",
    "注释": [{"文本": "① 本文作者…", "页码": 4, "bbox": [...]}],
    "正文": [{
      "序号": 1, "段落": 1,
      "文本": "碧玉妆成一树高，", "字数": 8,
      "注音": [{"字": "妆", "拼音": "zhuāng"}],
      "位置": [{"页码": 1, "pdf页序": 6, "bbox": [177.6, 296.0, 375.0, 318.9]}]
    }]
  }]
}
```

- `作者` 优先取正文里的作者行（`[唐] 贺知章`），没有就从脚注里解析
  （`本文作者林颂英`、`本文作者是意大利的达·芬奇，译者张复生`、
  `本文根据欧庆林的《…》改写`、`本文选自…`、`本文是民间故事，由李明才整理`），
  相应地填 `国别 / 译者 / 出处 / 整理者`。
- 一句话跨页时 `位置` 会有两条（前半页 + 后半页）；页尾没写完又没有下一页
  可接的句子保留 `跨页续句: true`。
- `--full` 按页输出，另加 `页面类型 / 页眉 / 页脚 / 右边栏 / 课后 / 插图数`；
  课后含 `生字.会认`（带拼音）、`生字.会写`、`练习[].要求 / 内容`。

语文园地页的排版和课文完全不同（导览图上的词条按位置摆放，一行里并排好几个），
所以单列一块，按「栏目 → 条目」保留，不做断句：

```jsonc
"语文园地": [{
  "标题": "语文园地一", "页码": [11, 12, 13],
  "栏目": [{
    "名称": "识字加油站", "页码": 11,
    "生字": [{"字": "亭", "拼音": "tíng"}, …],   // 栏目末尾的生字条
    "会写": ["剧", "场"],                        // 田字格里的描红字
    "条目": [{"文本": "湖心亭", "注音": [{"字": "亭", "拼音": "tíng"}], "bbox": [...]}, …],
    "选文": {"标题": "赋得古原草送别（节选）", "作者": "白居易", "年代": "唐", "正文": [...]}
                                                 // 日积月累的整首诗；抽成选文后不再重复进「条目」
  }]
}]
```

填空线还原成 `＿＿`（靠矢量横线判断，田字格里的中线不算）。

书末的识字表 / 写字表 / 词语表版式一样（按「阅读 / 识字」分组，一行一课，
行首是课号或「语文园地X」，排不下折到下一行），单列成附录：

```jsonc
"附录": [{
  "名称": "识字表", "页码": [113, 114, 115, 116], "条数": 36,
  "注释": [{"文本": "① 识字表中蓝色的字…", "bbox": [...]}],
  "分组": [{"名称": "阅读", "行": [
    {"标签": "1", "内容": [{"字": "咏", "拼音": "yǒng"}, {"字": "贺", "拼音": "hè"}, …]},
    {"标签": "语文园地一", "内容": [{"字": "亭", "拼音": "tíng"}, …]}
  ]}]
}]
```

每行的 `内容`：识字表是带注音的单字，写字表是单字，词语表是词语。

## 简化结构 `--struct`

只要「读得懂的一份」用这个，输出 `目录 / 课文 / 园地 / 附录` 四块，正文逐字注音：

```jsonc
{
  "目录": [{"类型": "课文", "单元": 1, "课号": "1", "标题": "咏柳", "页码": [1]},
           {"类型": "园地", "单元": 1, "标题": "语文园地一", "页码": [11, 12, 13]},
           {"类型": "附录", "标题": "识字表", "页码": [113, 114, 115, 116]}],

  "课文": [{"单元": 1, "课号": "1", "栏目": null, "课题": "古诗二首", "标题": "咏柳",
            "作者": "贺知章", "年代": "唐", "页码": [1],
            "全文": "碧玉妆成一树高，万条垂下绿丝绦。…",
            "拼音": "bì yù zhuāng chéng yī shù gāo ， wàn tiáo chuí xià lǜ sī tāo 。…"}],

  "园地": [{"单元": 1, "标题": "语文园地一", "页码": [11, 12, 13],
            "栏目": [{"名称": "识字加油站", "全文": "…", "拼音": "…"}]}],

  "附录": [{"模块": "识字表", "分组": "阅读", "序号": "1",
            "字": ["咏", "贺", …], "词": [], "拼音": ["yǒng", "hè", …]},
           {"模块": "词语表", "分组": "阅读", "序号": "2",
            "字": [], "词": ["春天", "寻找"], "拼音": ["chūn tiān", "xún zhǎo"]}]
}
```

注音规则：`拼音.split(" ")` 与 `全文` **逐字一一对应**（标点保留原样，空白对应空串）。
读音三级来源：

1. 课本标注过的生字 —— 以课本为准（多音字最可靠的依据）；
2. `struct.py` 里的 `PHRASE_FIX` —— 古诗文里 pypinyin 词典没收、单字默认又不对的词
   （似剪刀 sì、一行白鹭 háng、子鼠 zǐ、万颗子 zǐ、管子 zǐ）；
3. 其余先用 jieba 分词，再逐词送 pypinyin —— pypinyin 自带的简单切分会把
   「去年长颈鹿」切出「年长」而读成 `zhǎng`，分词后是 `cháng jǐng lù`。

用课本自己的 572 处注音回测过：pypinyin 单干错 16 处（2.8%），加 jieba 分词 17 处，
两者基本持平，但分词能修好「长颈鹿」这类真错，所以采用；这些位置本来也都由第 1 级
覆盖。装 `pypinyin-dict` 的大词库反而升到 4.5%，没有引入。剩下的风险是课本没标注、
又脱离常见词组的多音字，发现一个就往 `PHRASE_FIX` 里加一条（同时会加进 jieba 词典）。

## 网页阅读器 `viewer/`

纯静态，双击 `viewer/index.html` 就能用（不用起服务器），把 `out/struct.json`
拖进去或点「选择文件」即可。文件只在浏览器本地解析。

- **目录侧栏**：固定悬浮，正文滚动时始终在左侧，目录自己独立滚动；拖右边缘可改宽度
  （180–520px，双击复位，宽度记进 localStorage）。按单元分组（课文 / 语文园地 / 附录），
  可折叠、可收起成侧边书签；窄屏自动变抽屉。搜索框支持标题、课号，输入两个字以上还会全文检索。
- **阅读区**：拼音以 `<ruby>` 注在字上方，古诗按句居中、课文按句分行；
  拼音开关、楷体/宋体/黑体切换、字号加减，偏好和上次读到哪篇都记在 localStorage。
- **附录**：识字表/写字表按字卡排布，词语表按词卡排布，都带拼音。
- **多音字专题**：先加载 `struct.json`，再从侧栏加载 `zh-polyphone` 生成的
  `polyphone.json`。阅读器会进入专题校正模式，只保留含多音字的句子、园地栏目和
  附录单字行，弱化普通字并高亮多音字；点击高亮字可从该字的 `本册出现 / 常用 /
  不常用` 全部候选读音中直接选择，修改会写回当前课文数据。“返回全文”会保留
  已完成的修改和撤销记录，只退出专题视图。
- **注音修正**：正文里点一个字、或框选一段（最多 24 字）会弹出编辑框，
  输入用**数字声调**（`bi4` → bì，`lu:3` / `lv3` → lǚ，`5` 或留空 = 轻声），
  提交时自动转成带调拼音；格式不对会当场提示，`Enter` 提交、`Esc` 取消。
  附录的字卡/词卡点一下同样能改（词卡按整词输入，如 `chun1 tian1`）。
  改过的字注音显示为橙色。底部状态栏显示「已修正 N 处」，可看明细、撤销上一处、
  全部还原，以及**下载修正后的 struct.json**。修正会连同数据一起存进 localStorage，
  刷新后仍在。
- 快捷键：`←` `→` 翻篇，`[` 开合目录，`/` 搜索，`p` 拼音开关。
- 楷体需要本机装有楷体字体（macOS/Windows 自带；Linux 可装 `fonts-arphic-ukai`），
  否则会回退到宋体或黑体。

## 实现要点

| 模块 | 作用 |
| --- | --- |
| `pinyin_font.py` | 注音字体解码。课本拼音用方正 `HanyuXi-JZ`，带声调元音被映射成 ASCII 大写字母（`yGng` → `yǒng`）。码表由全书 1319 组「汉字 ↔ 注音」用 pypinyin 自动标定，无冲突 |
| `blocks.py` | 字形修补（私用区字形补 Unicode、去控制字符）；从 span 级重建行与单字（PyMuPDF 的 block/line 会被注音和填空线切碎），注音按坐标挂回汉字；矢量横线用于区分「填空线」和「分栏空隙」 |
| `regions.py` | 版面分区：页眉带（顶部 7.5%）、页脚带（底部 11.5%，只收页码和水印）、右边栏（贴右页边且与正文不同排）、正文区 |
| `semantics.py` | 页内语义单元：栏目/课题/标题/作者/年代/注释/正文；正文只在标点（。！？；，…，顿号不切）处断句，行尾无标点的行并入下一句；分段要求「缩进 + 上一行以句末点号收尾」，避免绕图排版的续行被当成新段 |
| `attribution.py` | 从脚注里解析作者、国别、译者、整理者、出处 |
| `appendix.py` | 书末识字表/写字表/词语表：按分组标签和行首课号切行，跨页折行接续 |
| `garden.py` | 语文园地页：按黑体小标题切栏目，条目按版面空隙切开，识别生字条/田字格/日积月累里的整首选文 |
| `struct.py` | 简化结构：目录索引、逐字注音（课本注音优先，其余 pypinyin） |
| `merge.py` | 把逐页结果合并成整篇课文：拼接跨页断句、延续跨页段落、汇总注释、重排序号 |

已知边界：

- 封面、版权页、目录、后记没有印刷页码，按前置页跳过抽取。
- 个别字形字体里没给 Unicode 映射（如「慕」字底的 ⺗，落在私用区 U+E823），
  在 `blocks.GLYPH_FIX` 里逐个补；全书目前只有这一个。
- 全书 41 个课文单元里，正课 32 篇（`课号` 非空）；其余是「我爱阅读」选文
  （`栏目` 字段标出）和快乐读书吧这类栏目页，按需过滤。
- 语文园地里的「口语交际」「写话」按栏目收进园地单元；「我爱阅读」是整篇选文，
  留在课文列表里（同一页上半是园地栏目、下半是选文时会按标签位置切开）。
- 本册课本正文可排到 x≈488（0.94 页宽），右边栏检测因此收得很紧；
  实际上全书右页边只有单元角标（归为页眉），`右边栏` 一直是空的。
