# 手写轨迹测试程序

在 `app` 目录运行（独立入口，不需要登录或 Worker）：

```sh
flutter run -d linux -t lib/handwriting_lab_main.dart
```

Android 可将 `linux` 替换为设备 ID。不支持 Web 文件读写。

1. 在四个田字格和三个不同宽度的拼音格中直接书写。
2. 切换笔宽和颜色，验证每一笔保留各自的样式。
3. 点击“保存轨迹文件”，状态栏显示文件位置、原始字节数、gzip 压缩后字节数及节省比例。默认使用应用支持目录中的 `handwriting-lab.json.gz`，也可输入其他路径；保存会覆盖该指定文件。文件只支持 gzip 格式，不兼容普通 JSON。
4. 清空书写区，点击“读取并还原”，下方显示文件渲染结果。
5. 调整预览缩放检查比例；也可关闭程序重新运行并读取同一文件。

gzip 无损压缩完整 UTF-8 JSON，不减少采样点或截断坐标精度。JSON 包含版本、格子类型与原始逻辑尺寸、格子顺序和间距、各笔画颜色（ARGB）、相对格高的笔宽，以及相对所属格子宽高的点坐标。越界坐标不截断，单点笔画渲染成圆点。布局按可用宽度换行，窄屏自动缩小过宽格子；不保存截图、OCR 结果或录音，不改正式作答流程。

自动化验证：

```sh
flutter test --no-pub test/handwriting_lab_test.dart
```

覆盖真实临时文件读写、多格与不同笔刷、越界坐标、空格、格式版本检查，以及文件往返前后在三种缩放尺寸下的逐像素渲染一致性。
